## Business Task

Evaluate the performance and impact of an A/B test

## Tools
SQL, Python (Pandas, NumPy), Statistical Analysis, A/B Testing (Z-test for proportions)

## Key Insights
- Measuring the effect of a new feature or change on key conversion metrics
- Determining the statistical significance of any observed differences in conversion rates using Z-tests for proportions.
-  Understanding user behavior across different segments by breaking down the A/B test results by dimensions. This helps identify which user groups are most affected by the test.
-  Providing data-driven insights to decide whether the tested variation should be launched, iterated upon, or discarded, ultimately aiming to optimise user experience and business outcomes.
